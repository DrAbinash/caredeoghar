DiagnoCenter

Diagnostic Center Billing ERP
Windows Installation Guide • Version 2026.05
For Windows 10 / Windows 11 PCs

What You Need

  • One main computer (Windows PC) to act as the server — this is the only PC that needs the installer
  • Other computers on the same Wi-Fi or LAN — no installation needed, just a web browser
  • Installer file: DiagnoCenter-Setup.exe (about 320 MB)
  • Minimum specs: Windows 10/11, 4 GB RAM, 1 GB free disk space
Tip: The main server PC should be the fastest computer in your clinic. It runs the database and the web server for everyone.

Step-by-Step Installation

1 Download the Installer

Get DiagnoCenter-Setup.exe from the download link provided. Save it to your Desktop or Downloads folder.

Note: The file is about 320 MB. It may take a few minutes to download depending on your internet speed.
2 Run the Installer

Double-click DiagnoCenter-Setup.exe. If Windows shows a "Windows protected your PC" warning:

  1. Click More info
  2. Click Run anyway

Follow the setup wizard:

  1. Click Next
  2. Choose install location (default is fine: C:\Program Files\DiagnoCenter\)
  3. Click Install
  4. Wait for installation (about 1-2 minutes)
  5. Click Finish
3 Start the Server

Go to your Desktop and double-click the DiagnoCenter shortcut (or go to C:\Program Files\DiagnoCenter\ and double-click DiagnoCenter.exe).

A black console window will open. Do not close this window. It is the server running.

Wait about 30 seconds. You will see:

Launcher ready
LAN ACCESS -- Other computers can reach this server at:
  http://192.168.1.50:8888/

The IP address will be different for your clinic. Write it down.

Important: Keep this black window open all day. If you close it, the server stops and other computers cannot connect. If you accidentally close it, just double-click DiagnoCenter.exe again.
4 Open Firewall (One-Time Setup)

If other computers cannot connect, you need to open the Windows firewall:

  1. Press Win + R, type cmd, press Enter
  2. Copy and paste this exact command, then press Enter:
netsh advfirewall firewall add rule name="DiagnoCenter" dir=in action=allow protocol=TCP localport=8888

You should see Ok. — done.

5 Use on Other Computers

No installation needed on other PCs. Just open a web browser:

  1. Open Google Chrome or Microsoft Edge
  2. In the address bar, type the LAN URL from Step 3, for example:
http://192.168.1.50:8888/

(Replace with the actual IP shown on your server)

  1. Press Enter
  2. The login screen appears — log in with your staff PIN

Useful Tips

Pin to taskbar: Right-click the DiagnoCenter shortcut → Pin to taskbar. Now you can start the server with one click.
Auto-start on boot: Press Win + R, type shell:startup, press Enter. Drag DiagnoCenter.exe into that folder. The server will start automatically every time the PC turns on.
Backup your data: The database is stored in C:\Program Files\DiagnoCenter\data\pgsql\. Copy the entire data folder to a USB drive regularly. Patient data cannot be recreated if lost.
Update without reinstalling: When a new version is available, use DiagnoCenter-Update.zip inside the ERP (go to Settings → System Update). This patches the app without losing any data.

Troubleshooting

ProblemSolution
"Windows protected your PC" when running the installer Click More info → Run anyway. The software is not digitally signed yet.
"Cannot GET /" in the browser The server is still starting. Wait 30 more seconds and refresh the page.
Other PC says "This site can't be reached" Check Step 4 (firewall). Also make sure both PCs are on the same Wi-Fi network.
Forgot the LAN IP address On the server PC, press Win + R, type cmd, type ipconfig, look for "IPv4 Address" under Wi-Fi or Ethernet.
App is slow on client computers The server PC should be the fastest computer. If it is old or low on RAM, the whole clinic will feel slow.
Black console window shows errors Take a screenshot and contact support. Common causes: port already in use (another program is using port 8888).

Security Checklist

  • ☐ Change the default admin PIN after first login
  • ☐ Set up regular backups (copy the data folder)
  • ☐ Enable Windows automatic updates on the server PC
  • ☐ Use a strong Windows password on the server PC
  • ☐ Do not expose port 8888 to the internet without a VPN

Need Help?

Contact your software support and provide:

  1. The LAN URL (e.g., http://192.168.1.50:8888/)
  2. A screenshot of any error message
  3. Whether the black console window shows "Launcher ready"
