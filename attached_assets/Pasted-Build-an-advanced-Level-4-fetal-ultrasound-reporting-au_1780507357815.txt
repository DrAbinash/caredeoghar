Build an advanced Level-4 fetal ultrasound reporting automation module inside my existing ERP/RIS/PACS system.

Goal:
Create a fast, safe, radiologist-review workflow where USG fetal studies are automatically received, classified, populated with measurements, converted into draft reports, reviewed by doctor, finalized, signed, stored, and sent to patient.

Do NOT replace radiologist judgment. AI must only draft and assist. Final report must require human verification before release.

- ERP already has patient registration, billing, reporting, radiology workflow, PACS integration.

- Modalities include USG, MRI, CT, X-ray.
- ERP has internal API routes for radiology worklist and reports.
- Use the current project structure and database style.
- Keep UI clean, fast, and suitable for diagnostic center daily workflow.

   Create an AI report draft button:

AI should:

- Use extracted/manual values.
- Select correct template.
- Write clean radiology-style report.
- Highlight missing required fields.
