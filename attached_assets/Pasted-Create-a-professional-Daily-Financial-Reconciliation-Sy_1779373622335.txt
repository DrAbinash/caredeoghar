Create a professional “Daily Financial Reconciliation System” for my Diagnostic Center ERP.

Use the following accounting logic exactly:

VARIABLES:

- X = Total Bills Generated Today
- Y = Old Dues Collected Today
- Z = Cancelled Bills Amount
- A = Outstanding / Pending Dues
- B = Cash Expenses
- C = Digital Collection (UPI/Card/Net Banking)

FORMULAS:

1. Gross Collection = X + Y

2. Net Total Collection =
   (X + Y) - (Z + A + B)

3. Physical Cash In Hand =
   Net Total Collection - C
